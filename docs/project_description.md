# Описание проекта: Каталог образовательных учреждений для поступления

## 1. Актуальность
Выбор места обучения после 9 или 11 класса — один из ключевых этапов в жизни молодого человека и его семьи. Существующая информация часто разрознена, официальные сайты учреждений перегружены бюрократическими деталями, а отзывы трудно найти и верифицировать. Отсутствует единая платформа, позволяющая сравнить учреждения разных городов на основе реального опыта обучающихся и четких критериев (рейтинг, направление подготовки, локация). Данный проект решает проблему навигации и выбора, предоставляя структурированный каталог с системой отзывов и персонализированными рекомендациями.

## 2. Целевая аудитория
*   **Основная группа**: Выпускники 9 и 11 классов, планирующие поступление в колледжи, техникумы и вузы.
*   **Вторичная группа**: Абитуриенты любого возраста, рассматривающие возможность получения среднего профессионального или высшего образования, смены профессии, повышения квалификации.
*   **Ограничение по возрасту**: Нижняя граница — окончание 9 класса; верхняя граница **не установлена**.

## 3. Функциональные возможности

### MVP (Минимально жизнеспособный продукт)
1.  **Авторизация и регистрация**: Вход в систему только для зарегистрированных пользователей. Без авторизации доступны только страницы входа и регистрации.
2.  **Профиль пользователя**: Редактирование личных данных (ФИО, возраст, город проживания).
3.  **Каталог учреждений**:
    *   Просмотр списка учебных заведений.
    *   Фильтрация по городу и направлению подготовки (на основе предпочтений пользователя).
    *   Карточка учреждения с основной информацией.
4.  **Система отзывов и оценок**: Возможность оставить текстовый отзыв и оценку учреждению.
5.  **Рейтинг и статистика**: Автоматический расчет среднего рейтинга учреждения и города на основе отзывов.
6.  **Избранное**: Добавление учреждений в список «Избранное» для быстрого доступа и возможность удаления из списка (как из карточки, так и из общего списка).
7.  **Ролевая модель**:
    *   **User**: Доступ к каталогу, профилю, отзывам, избранному.
    *   **Admin**: Полный доступ, включая управление контентом (учреждения, модерация отзывов).

### Задел на будущее (Roadmap)
*   Расширенная система уведомлений.
*   Детальная аналитика поступлений (проходные баллы прошлых лет).
*   Интеграция с официальными API приемных комиссий.
*   Двухфакторная аутентификация (2FA) для повышения безопасности.

## 4. Технологии
*   **Frontend**: JavaScript, библиотека React (SPA), адаптивная верстка.
*   **Backend**: Python (Web-фреймворк), REST API.
*   **База данных**: PostgreSQL (реляционная СУБД).
*   **Развертывание**: Контейнеризация (опционально), хостинг приложения и БД.
*   **Инфраструктура**: Terraform не используется.

## 5. Ожидаемый результат
Разработанный и развернутый веб-сервис, готовый к эксплуатации, позволяющий пользователям эффективно искать и сравнивать образовательные учреждения, опираясь на отзывы и рейтинг. Проект полностью соответствует требованиям учебных модулей УП.02 и УП.11, включая наличие документации, диаграмм и скриптов БД.

## 6. Термины и соглашения

### Доступ к системе
*   **Неавторизованный доступ**: Разрешен только к страницам **Вход** и **Регистрация**. Любые другие разделы сайта перенаправляют на страницу авторизации.
*   **Авторизованный доступ**: Предоставляется после успешного ввода учетных данных.

### Роли пользователей
*   **`user`**: Стандартный пользователь, имеющий доступ к функционалу каталога, управления профилем, избранным и отзывами.
*   **`admin`**: Пользователь с расширенными правами, включающими управление справочниками (города, учреждения) и модерацию контента.

### Понятие «Реалтайм» (Real-time)
Под актуальностью рейтинга в контексте данного проекта понимается:
*   Мгновенный пересчет среднего балла и рейтинга при добавлении нового отзыва.
*   Отображение обновленных данных при следующем запросе к странице учреждения или списку городов (модель request-response).
*   *Примечание*: Использование WebSocket для пуш-уведомлений об изменении рейтинга возможно в будущих версиях, но не является обязательным для MVP.
